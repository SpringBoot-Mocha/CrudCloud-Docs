# CrudCloud Frontend

Esta sección documenta el **Frontend de CrudCloud**, la aplicación web que permite a los usuarios:

- Registrarse e iniciar sesión.
- Crear, administrar y eliminar instancias de bases de datos.
- Gestionar planes de suscripción y pagos.
- Visualizar de forma clara el estado de sus servicios.

El frontend está construido con:

- **React** (Vite)
- **Tailwind CSS**
- Integración con el backend de CrudCloud vía REST API.
