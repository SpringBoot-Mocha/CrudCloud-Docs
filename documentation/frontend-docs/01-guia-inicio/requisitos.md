# Requisitos para el Frontend

Antes de ejecutar el frontend de CrudCloud, asegúrate de tener instalado:

- **Node.js** 18 o superior
- **npm** 8 o superior
- **Git**
- Acceso a la URL del backend (local o en servidor)

Opcional (para un entorno más realista):

- Variables de entorno configuradas con la URL base del backend de CrudCloud.
