# Ejecución del Frontend

Una vez instaladas las dependencias y configuradas las variables de entorno, puedes ejecutar el proyecto.

## Servidor de desarrollo

Para levantar el servidor de desarrollo:

```bash
npm run dev

Por defecto, la aplicación estará disponible en:

http://localhost:5173

Build de producción

Para generar una build optimizada:

npm run build

Esto generará los archivos estáticos en la carpeta:

dist/

Vista previa de la build

Puedes hacer una vista previa de la build de producción con:

npm run preview

    Este comando levanta un servidor local que sirve el contenido de dist/, simulando más fielmente un entorno de producción.
